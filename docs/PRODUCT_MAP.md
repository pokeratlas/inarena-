# INARENA Product Map

## Platform
INARENA is a sports × lifestyle platform with offline and online poker experiences.

## Product surfaces

### INARENA Player
- Telegram Mini App / mobile-first client
- Identity and profile
- Offline tournament registration
- Online lobby and gameplay
- Player history
- Rankings and achievements

### INARENA Online
- NL Hold'em runtime
- Cash tables
- Tournament tables
- Realtime state
- Action sequencing
- Reconnect/replay
- Hand history
- Chip ledger

### INARENA Clubs
- Club profile
- Offline tournaments
- Registration
- Player attendance
- Club league
- Series / Nationals / Finals

### INARENA Operator
- Tables
- Tournaments
- Players
- Blind schedules
- Rebuy / add-on windows
- Internal chip balances
- Audit
- Reports
- Recovery controls

## Shared Platform Core
- Identity
- Player Profile
- Permissions
- Realtime
- Ledger
- Event history
- Rankings
- Analytics
- Notifications
- Audit

## Product principle
UI never owns game rules. The server is authoritative for game state, permissions, sequencing, balances and settlement.
